# Gigma в StoryForge

Встроенный редактор основан на [Gigma 0.2.9, ревизия ed22a66](https://github.com/sunakle/gigma/tree/ed22a66bf3a71e418f84ea1ed2db040adb8c38c5). В этой папке находятся исходники холста, модели документа, панелей, локализации и интеграции с Illustrator. Собранные файлы входят в поставку StoryForge.

Gigma Studio открывает холст текущего проекта StoryForge. В заголовке отображается название проекта. Страницы, слои, изображения и переходы прототипа сохраняются вместе со сценарием в файле `.sfproj`. Команды создания, открытия и сохранения проекта на холсте относятся к StoryForge. Язык и тема следуют настройкам приложения.

Команда **Импортировать страницы из .gigma…** добавляет страницы на холст и сохраняет вложенность слоёв и переходы между кадрами. На новом холсте импортированные страницы занимают место пустой стартовой страницы. Импорт можно отменить одним действием. Экспорт поддерживает Gigma, SVG и PNG. Для импорта и экспорта AI используется установленный на компьютере Adobe Illustrator.

## Сборка редактора

В этом каталоге выполните:

```powershell
npm ci
npm run build
```

Сценарий обновляет `src/gigma/editor.js`, `editor.css`, список лицензий зависимостей и модуль Illustrator в `src/native/gigma`. Внешний вид StoryForge задаёт `src/gigma/story-studio.css`. Локальный каталог с установленными зависимостями совместимых версий можно передать сборщику через переменную `GIGMA_NODE_MODULES`.
