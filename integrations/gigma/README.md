# Gigma в StoryForge

Встроенный редактор основан на [Gigma 0.2.9, ревизия ed22a66](https://github.com/sunakle/gigma/tree/ed22a66bf3a71e418f84ea1ed2db040adb8c38c5). В этой папке находятся исходники холста, модели документа, панелей, локализации и интеграции с Illustrator. Собранные файлы входят в поставку StoryForge.

Каждая вкладка открывает один макет в отдельном изолированном фрейме. Документ вместе с изображениями передаётся рабочему пространству StoryForge и хранится в проекте. Язык и тема следуют настройкам StoryForge. Импорт файла `.gigma` открывает новый макет, а экспорт поддерживает Gigma, SVG и PNG. Операции с AI используют установленный на компьютере Adobe Illustrator.

## Сборка редактора

В этом каталоге выполните:

```powershell
npm ci
npm run build
```

Сценарий обновляет `src/gigma/editor.js`, `editor.css`, список лицензий зависимостей и модуль Illustrator в `src/native/gigma`. Внешний вид StoryForge задаёт `src/gigma/story-studio.css`. Локальный каталог с установленными зависимостями совместимых версий можно передать сборщику через переменную `GIGMA_NODE_MODULES`.
