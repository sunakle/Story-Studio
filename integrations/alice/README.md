# Диктовка Алисы в StoryForge

Эта интеграция рассчитана на Станцию Лайт 2 с настроенным пользовательским помощником и YaPanel на Windows. Голосовая служба станции, обработчик очереди YaPanel и редактор работают совместно. Установщик StoryForge обновляет редактор на ПК.

- [Изменения помощника станции](station/assistantd-storyforge.patch) добавляют сеанс диктовки к помощнику с распознаванием фраз Алисы и существующей очередью команд ПК. В патче также есть тесты поведения. Это частичное изменение исходников совместимого помощника.
- [Клиент для службы Windows](pc/storyforge_dictation.py) доставляет текст в запущенный редактор. При явном старте он может открыть установленный StoryForge. [Изменения для обработчика команд YaPanel](pc/yapanel-agent.patch) подключают этот клиент к очереди.
- В приложении индикатор **Идёт диктовка** показывает, когда редактор готов добавлять текст. После фразы **«Стоп, диктовка»**, кнопки **Остановить** или смены проекта запоздалые фразы прежнего сеанса отклоняются. Пауза в речи завершает текущую фразу. Длительная тишина завершает сеанс.

Для проверки ПК используются синтетические фразы и отдельный проект. Команда `node tools/test-alice-dictation.mjs` проверяет окно редактора, а `python -m unittest discover -s integrations/alice/pc` — доставку команд. Обновление службы колонки выполняется отдельно, с сохранением её настроек.
